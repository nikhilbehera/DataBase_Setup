# Database Setup with Python and MySQL

## Project Overview
This project demonstrates how to connect Python with a MySQL database and perform basic database operations.

The main objective is to understand database connectivity and how Python applications interact with MySQL.

## Technologies Used
- Python
- MySQL
- MySQL Connector (if used in the project)

## Project Structure

```text
DataBase_Setup/
│
├── database.py
└── README.md
```

## Features
- Python and MySQL database connectivity
- Database connection management
- Basic SQL operations (as implemented)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/nikhilbehera/DataBase_Setup.git
```

2. Navigate to the project folder:

```bash
cd DataBase_Setup
```

3. Install the required package (if using MySQL Connector):

```bash
pip install mysql-connector-python
```

## Run the Project

```bash
python database.py
```

- Understand MySQL database connectivity.
